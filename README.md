# 🟣 NKZ NET TOOL

**Ferramenta de diagnóstico de rede para Windows usando Batch (.BAT).**

O NKZ NET TOOL é um projeto educacional com interface CMD, desenvolvido para facilitar a consulta de informações de rede e praticar comandos do Windows.

## 🚀 Funcionalidades

- 🌐 Consulta de IPv4, IPv6, gateway e DNS
- 📡 Teste de conectividade com a internet
- ⚡ Teste de latência usando PING
- 🔌 Visualização de conexões de rede ativas
- 🛠️ Consulta de portas e processos
- 🧹 Limpeza do cache DNS
- 🔄 Renovação do endereço IP via DHCP
- 🖥️ Acesso rápido às ferramentas do Windows
- 📄 Geração de relatório de diagnóstico em TXT

## 💻 Requisitos

- Windows 10 ou Windows 11
- Prompt de Comando (CMD)
- Permissões de administrador para algumas funções

## 📥 Como executar

1. Baixe ou clone este repositório.
2. Localize o arquivo `NKZ-NET-TOOL.bat`.
3. Execute o arquivo com dois cliques.
4. Escolha uma opção no menu.
5. Para funções administrativas, execute como administrador quando necessário.

## 🎯 Objetivo

Praticar programação Batch, comandos do Windows, diagnóstico de redes e fundamentos de cibersegurança.

## ⚠️ Aviso

Projeto educacional. Utilize as funções de diagnóstico e gerenciamento somente em computadores e redes que você tem autorização para administrar.
