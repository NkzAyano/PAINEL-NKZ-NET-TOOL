# NKZ NET TOOL

Painel CMD do Windows para diagnóstico básico de rede, escrito em Batch (`.bat`).

## Funções
1. Consultar IP local e IPv6.
2. Consultar gateway, DNS e adaptadores.
3. Testar conexão com a internet.
4. Testar latência (ping) para um endereço informado.
5. Consultar informações de IP e configuração de rede.
6. Mostrar conexões de rede ativas.
7. Mostrar portas e processos associados às conexões locais.
8. Limpar o cache DNS (com confirmação).
9. Renovar o endereço IP via DHCP (com confirmação).
10. Abrir o Gerenciador de Tarefas e o painel de conexões.
11. Salvar relatório de diagnóstico em arquivo de texto.
12. Atualizar informações e voltar ao menu.

## Como executar
1. Extraia o ZIP.
2. Dê dois cliques em `NKZ-NET-TOOL.bat`.
3. Se a janela fechar, abra o CMD na pasta e execute `NKZ-NET-TOOL.bat` para ver eventuais mensagens.

Não exige Python nem bibliotecas extras.

## Avisos
- Renovar o IP pode interromper a internet temporariamente.
- O relatório inclui informações locais de rede e processos; revise antes de compartilhar.
- Alguns nomes de campos podem variar conforme o idioma do Windows.
- Use apenas no seu computador ou em redes nas quais você tem autorização.
